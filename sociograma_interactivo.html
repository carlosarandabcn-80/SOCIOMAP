Para visualizar los retratos del grupo desmarca «Mostrar códigos y ocultar fotografías». Se trata de datos identificables: evita mostrar esta vista ante personas no autorizadas. Arrastra los nodos o selecciona uno y pulsa los botones de dirección para moverlo sin arrastrar. Con teclado: Tab para acceder; flechas para mover; Enter para seleccionar; espacio para fijar; Escape para salir de la selección. Usa los botones para ampliar. Las posiciones se guardan en el estudio.

Exportar el estudio

PNG y SVG incluyen el filtro actual, grupo, fecha y leyenda. El PDF añade indicadores, barras, tabla y criterios de análisis. Exportación con códigos y sin fotografías por defecto. Para exportar imágenes reales, marca expresamente «Incluir nombres y grupo originales». Las copias JSON identificadas contienen fotografías; los CSV nunca las incluyen.

Comparar dos mediciones

Carga una copia anterior JSON o CSV del mismo estudio. Deben coincidir participantes, identificadores, criterio y reglas, con respuestas completas. Para otra fecha utiliza «Nueva medición del mismo grupo» en la matriz. Los cambios son descriptivos y no prueban el efecto de una intervención.
